# 💊 MediScan AI

AI-powered medicine safety app — verify medicines, read prescriptions, check interactions, and report fake medicines to government.

## ✨ Features

- 🏠 **Dashboard** — Real-time stats and recent activity
- 💊 **Medicine Verifier** — Barcode ya naam se genuine/fake check
- 📸 **Prescription Reader** — Photo → clean text + download (TXT/CSV)
- ⚗️ **Interaction Checker** — 2-5 medicines ka pair-wise safe/unsafe
- 🩺 **Symptom Suggester** — Symptoms → safe OTC suggestions
- 📢 **Complaints** — Fake medicine report karo government tak
- 🛠️ **Department Panel** — Govt officials resolve complaints
- 💾 **Database** — Browse 12+ medicines

## 🚀 Deploy on Streamlit Cloud

1. Push to GitHub:
   ```bash
   git init
   git add .
   git commit -m "MediScan AI"
   git branch -M main
   git remote add origin https://github.com/YOUR_USERNAME/mediscan-ai.git
   git push -u origin main
   ```
2. [share.streamlit.io](https://share.streamlit.io) → New app
3. Repo select → `app.py` → **Deploy**
4. No API keys needed ✅

## 🛠️ Tech Stack

- Streamlit + Pandas + Pillow
- Tesseract OCR
- No APIs · No keys · 100% local
