# 💊 MediScan AI

AI-powered medicine safety app — verify medicines with image upload, read prescriptions, check symptoms, and report fake medicines.

## ✨ Features

- 🏠 **Dashboard** — Real-time stats + quick actions
- 💊 **Verify Medicine** — Image upload → genuine/fake detection
- 📸 **Read Prescription** — Photo → clean medicine list + download
- 🩺 **Symptom Checker** — Type symptoms → OTC suggestions
- 📢 **Complaints** — File complaint → track → upvote + comments
- 🛠️ **Department Panel** — Govt officials resolve complaints

## 🚀 Deploy on Streamlit Cloud

Push to GitHub → [share.streamlit.io](https://share.streamlit.io) → New app → select repo → `app.py` → Deploy

## 🛠️ Tech Stack

- Streamlit · Pandas · Pillow · Tesseract OCR
- Zero API keys · 100% local
